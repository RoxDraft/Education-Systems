# ระหว่างกาล — Art & Science Odyssey

เกมสำรวจภาษาไทย 3 ยุค: เวิร์กช็อปดาวินชี ห้องทดลองแสงของนิวตัน และแล็บมารี คูรี

## เปิดเล่น

เปิด `dist/index.html` ด้วย Chrome, Edge หรือ Firefox รุ่นปัจจุบัน ไม่ต้องติดตั้งส่วนเสริม หากใช้ไฟล์ ZIP ให้แตกไฟล์ทั้งหมดไว้ในโฟลเดอร์เดียวกัน แล้วเปิด `index.html`

คลิก/แตะพื้นเพื่อเดิน คลิกตัวละครหรือวัตถุเพื่อเดินไปสำรวจ หรือใช้ WASD / ลูกศรและกด E เมื่ออยู่ใกล้ ปุ่มในแผงการเดินทางพาไปจุดสำรวจได้ และมือถือมีปุ่มเดินบนฉาก

## เป้าหมาย

แต่ละยุคมี 3 ร่องรอย: บันทึกคำถามจากบทสนทนา ตอบคำถามจากจุดสังเกต และทำภารกิจทดลอง ไม่มีเวลาจำกัดและกลับมาสำรวจซ้ำได้

- ดาวินชี: เลือกสื่อ ปรับขอบเงา และเก็บการทดลองอย่างน้อย 2 ค่าเพื่อเปรียบเทียบ
- นิวตัน: ดูการแยกแสง การเลือกสีเดียวผ่านปริซึมอีกชิ้น และการรวมแสงกลับ
- คูรี: วัดตัวอย่างจำลอง 3 ชนิด เปรียบเทียบค่าเฉลี่ย และเลือกวิธีตรวจสมมติฐานต่อ

มีบทเชื่อมปัจจุบัน แหล่งข้อมูล สมุดบันทึกส่วนตัว ดาวน์โหลดสมุดเป็น TXT และเสียงบรรยากาศที่ผู้เล่นเลือกเปิดเอง

## ข้อมูลและข้อจำกัด

ความคืบหน้าเก็บใน localStorage ของเบราว์เซอร์ ไม่ส่งขึ้นเซิร์ฟเวอร์หรือซิงก์ข้ามเครื่อง การเปิดไฟล์ในเครื่องอาจมีนโยบายจัดเก็บต่างกันตามเบราว์เซอร์ ควรดาวน์โหลดสมุดสำรอง

ฉาก ภาพ ตัวละคร บทพูด และค่าการวัดสร้างขึ้นเพื่อการเรียนรู้ ไม่ใช่ภาพถ่ายสถานที่จริง คำพูดจริง หรือแบบจำลองฟิสิกส์เชิงปริมาณ เกมย่อเหตุการณ์หลายช่วงเวลาและไม่สอนขั้นตอนทดลองกับสารกัมมันตรังสี

แหล่งข้อมูลจาก National Gallery, Newton Project, Nobel Prize และ National Cancer Institute ระบุลิงก์ไว้ในเกมและใน `dist/data.js`

## การตรวจสอบ

ตรวจไวยากรณ์ JavaScript และทดสอบ Chrome แบบแยก: การเดินและเปิดบทสนทนา การเข้าถึงทั้ง 9 จุด ภารกิจทั้ง 3 ผลตอบกลับเมื่อตอบผิด การเก็บความคืบหน้า/บันทึกหลัง reload เสียง และขนาดหน้าจอมือถือ ตรวจภาพหน้าจอคอมพิวเตอร์และมือถือแล้ว


## รุ่นเนื้อเรื่องต่อเนื่องและโลก 3D

แต่ละยุคมี 7 ช่วงเรื่อง (รวม 21 ขั้น): รับโจทย์ → เก็บวัสดุและคุยกับผู้ร่วมงาน → วางแผน → ทดลอง → รับคำแนะนำจากผลที่บันทึก → ปรับงานและทดลองซ้ำ → ส่งงานร่วมกับทีม

ดาวินชีมีการลงสี 3 วิธี บันทึกค่าและสื่อแต่ละครั้ง แล้วรับคำแนะนำตามผลที่ทำ ผู้ช่วยคนหนึ่งเป็นตัวละครสมมติ ส่วนเด เปรดิสอิงทีมรับงานแท่นบูชา นิวตันมีจดหมายและข้อวิจารณ์ของเครือข่ายภายหลัง ค.ศ. 1666 ไม่ใช่เพื่อนร่วมทดลองที่อยู่ในห้องเดียวกัน คูรีมีบทบาทของปิแอร์และเบมงต์

ภาพเป็นโมเดล 3D สร้างจากรูปทรงพื้นฐาน มีวัสดุ แสงและเงา หมุนกล้องด้วยคลิกขวาลากหรือปุ่ม ↶ ↷ และซูมด้วยล้อเมาส์ เปิด Ray Tracing ได้: shader คำนวณจุดตัดรังสีกับกล่อง/ทรงกลม คำนวณเงาและการสะท้อนหนึ่งชั้น พร้อมลดความละเอียด ไม่ใช่ Full Path Tracing หรือภาพสมจริงระดับภาพถ่าย ป้ายและวัสดุโปร่งใสบางชิ้นใช้เฉพาะโหมด 3D ปกติ

สถานที่: คูรีอิงภาพ hangar ของ ESPCI และคำบรรยายโรงเรือนไม้ พื้นบิทูเมน หลังคากระจก โต๊ะเก่าและเตา นิวตันอิงบ้าน Woolsthorpe Manor ของ National Trust เวิร์กช็อปดาวินชีตีความบริบทยุคมิลาน ทั้งหมดมีการปรับสัดส่วนและเปิดผนัง/หลังคาบางส่วนเพื่อเล่น ไม่ใช่แบบสำรวจอาคารที่ยืนยันตรงทุกตำแหน่ง ปุ่ม “สถานที่นี้อิงอะไร?” ระบุแหล่งข้อมูล

ตรวจสอบใหม่: เส้นทางเข้าถึง 24 จุด, ลำดับเรื่องทั้ง 21 ขั้น, กระเป๋าวัสดุ, บทบาทผู้ร่วมงาน, การลงสีสามวิธี, คำแนะนำตามผล, เงื่อนไขปรับงานจริง, ความคืบหน้าหลังโหลดใหม่, โหมด 3D/Ray Tracing และขนาดหน้าจอมือถือ


## รุ่นมุมมองบุคคลที่หนึ่งและวัสดุ voxel

เริ่มจากสายตาผู้เล่นที่ระดับ 1.68 หน่วย ลากบนฉากเพื่อหันและก้มเงย WASD/ลูกศรเดิน E/คลิกสำรวจ 1/2/3 ถือของ F/ปุ่มใช้ของเริ่มงานเมื่ออยู่ใกล้โต๊ะและถือเครื่องมือที่ตรงกับงาน มีปุ่มสลับภาพรวมและปุ่มเต็มหน้าจอโดยผู้เล่นกดเอง มือถือใช้การลากมองและปุ่มเดิน

วัสดุมีลายและ bump จากภาพ procedural ที่สร้างขึ้นใหม่: ไม้ กระดาษ หิน/ปูน ผ้า และโลหะ ขวดมีเปลือกแก้วโปร่งใสและของเหลว ปริซึมเป็นทรงสามเหลี่ยม พู่กันมีด้าม/ปลอก/ขนแยกชิ้น เครื่องวัดมีขั้วและหน้าปัด โมเดลสไตล์ voxel เป็นงานต้นฉบับ ไม่ใช้ไฟล์ Minecraft หรือม็อดภายนอก

ตรวจรายละเอียดก่อนกดหยิบ จากนั้นสิ่งของเข้า hotbar และแสดงเป็นโมเดลในมือ งานดาวินชีเริ่มด้วยพู่กัน งานนิวตันเริ่มด้วยปริซึม งานคูรีใช้แบบตรวจเครื่องมือ ข้อความและการตอบกลับจะแจ้งเมื่อถือผิดชิ้นหรืออยู่ไกลโต๊ะ การทดลองเชิงรายละเอียดเปิดเป็นโต๊ะกิจกรรมที่มีภาพและตัวควบคุม

ใบหน้า ผม เครื่องแต่งกาย และสัดส่วนมีโปรไฟล์แยกสำหรับดาวินชี นิวตัน มารี ปิแอร์ เบมงต์ เด เปรดิส และผู้ช่วย เป็นโมเดลตีความ voxel ไม่ใช่โมเดลสแกนหรือภาพเหมือนที่ยืนยันตรงตามอายุในฉาก ภาพอ้างอิงนิวตัน ค.ศ. 1689 และภาพดาวินชีช่วงปลายชีวิตใช้ศึกษาลักษณะเด่น ข้อจำกัดระบุในแหล่งข้อมูลในเกม

ทดสอบการเคลื่อนที่ด้วยคีย์จริง ระดับกล้อง การหยิบที่ต้องกดยืนยัน การถือของและใช้ที่โต๊ะ ภารกิจครบ 21 ขั้น ความคืบหน้าหลังเปิดใหม่ โมเดลแต่ละโปรไฟล์ โหมด Ray Tracing และหน้าจอมือถือ


## รุ่นทำงานบนเครื่องมือในห้อง

การวาดเกิดบน texture ของผืนภาพ 3D ในเวิร์กช็อปโดยตรง ใช้ raycast แปลงตำแหน่งเมาส์/สัมผัสเป็น UV ของภาพ เลือกสี ผสมสองสีตามสัดส่วน เลือกขนาด ความทึบ และพู่กันนุ่ม/ปาด/แต้ม รอยสะสมตามการลาก มี undo/redo และดาวน์โหลด PNG ผสมสีเป็นแบบจำลองเชิงภาพ ไม่ใช่สูตรเม็ดสีจริง

ภาพ PNG และสถิติรอยพู่กันเก็บแยกใน localStorage ชื่อ era-walk-paint-v1 บันทึกเมื่อจบรอย พื้นภาพเริ่มจากแบบร่างต้นฉบับของเกม ไม่ใช่ภาพประวัติศาสตร์ โหมดวาดใช้ภาพ 3D ปกติเพื่อแสดง texture ที่เปลี่ยนทันที

ผู้เล่นรับคำแนะนำและส่งงานจากแผงข้างภาพได้ โดยไม่เปิด dialog ทดลอง คำแนะนำเป็นกฎจากขนาดพู่กัน ความทึบ จำนวนสีและวิธี ไม่ใช่การประเมินความงามด้วย AI ปุ่ม B เก็บเครื่องมือกลับไปสำรวจ ปุ่มแผงเครื่องมือบนมือถือย่อขยายได้

ปริซึมมีแสงในฉากให้สลับแยก/เลือกสีเดียว/รวมกลับ และมีชิ้นแก้วประกอบ เครื่องวัดเปลี่ยนเข็มและค่าบนหน้าปัดเมื่อเลือกบัตรข้อมูล ค่ายังคงเป็นข้อมูลสมมติ ไม่มีการเชื่อมอุปกรณ์จริงหรือสูตรจัดการสาร

ตัวละครเดินเส้นทางสั้น ๆ หลีกเลี่ยงจุดทำงาน มีปุ่มเดินนำและบทสนทนาโต้ตอบแบบผู้บรรยาย/ผู้ทดลอง ป้ายคำพูดอยู่ในฉาก สามารถเปิดเสียงอ่านสังเคราะห์ตามเสียงที่เครื่องรองรับ บทสนทนาทั้งหมดเป็นข้อความแต่งเพื่อการเรียนรู้

การเดินรองรับ WASD ตาม physical key code จึงใช้ได้เมื่อเปิดแป้นพิมพ์ไทย ปุ่มเดินแสดงบนคอมพิวเตอร์ด้วย โฟกัสปุ่มและค้าง Enter/Space เพื่อเดินได้ ช่องกรอก/slider ยังคงรับคีย์ตามปกติ

ตรวจด้วยการส่ง pointer จริงลงผิวภาพ 3D ตรวจ pixel เปลี่ยน, ผสมสี, พู่กันสามแบบ, undo/redo, reload ภาพตรงกับที่บันทึก, ขั้นรับคำแนะนำและปรับงานในฉาก, พิกัดตัวละครเดินจริง, คีย์ไทยกับ KeyW, ปุ่มเดิน Enter, เครื่องมือในฉากและหน้าโทรศัพท์


## รุ่นเมนู 9 บทและคำแนะนำเฉพาะจุด

เพิ่มเอด้า เลิฟเลซ (คำสั่งและลำดับ), ฟลอเรนซ์ ไนติงเกล (แยกข้อมูลและสื่อสาร), ไทอิจิ โอโนะ (คอขวดและงานค้าง), นอร์แมน บอร์ล็อก (พันธุ์พืชกับเงื่อนไขน้ำ), เรเชล คาร์สัน (ผลข้างเคียงในระบบ) และทิม เบอร์เนิร์ส-ลี (ลิงก์กับกติการ่วม) รวมเป็น 9 บท มีผู้ร่วมงาน บทบาทเครือข่าย แหล่งข้อมูล และเรื่องราว 7 ขั้นต่อบท เมนูเลือกบทแยกจากกิจกรรมเดิม และเก็บความคืบหน้าเดิมไว้

คำแนะนำดาวินชีอ่านพิกเซลบนงานจริงเพื่อเลือกบริเวณมืดหรือขอบที่มีความต่างสูง วงตำแหน่งบนผืนภาพ พร้อมคำอธิบายเชิงตำแหน่ง แยกชั้นสาธิตซึ่งไม่แก้ภาพต้นฉบับ สลับก่อน/สาธิตได้ ผู้เล่นเลือกลองเองหรือนำชั้นสาธิตไปใช้เองได้ คำแนะนำเป็นการวิเคราะห์ค่าสีและขอบอย่างง่าย ไม่ใช่การตีความเนื้อหาหรือประเมินความงามแบบผู้เชี่ยวชาญ

การลองทำตามตรวจพื้นที่ที่ลงพู่กัน แล้วเปรียบเทียบความสว่างหรือความต่างขอบก่อน–หลัง มีพู่กันเกลี่ยสีเดิม (smudge) เพิ่มจากพู่กันเดิม ภาพต้นฉบับและ PNG ที่ดาวน์โหลดไม่รวมวงแนะนำหรือชั้นสาธิตที่ยังไม่ได้ยอมรับ

ตรวจ: เมนู 9 บท, การจบเรื่องครบ 7 ขั้นสำหรับ 6 คนใหม่, เงื่อนไขทดลองและปรับงานต่างกัน, การตรวจตำแหน่งจริงจากพิกเซล, ชั้นสาธิตไม่เปลี่ยนงานจริง, พู่กันทำให้จุดที่เลือกสว่างขึ้น, ความคืบหน้าหลังเปิดใหม่ และเมนูมือถือ
