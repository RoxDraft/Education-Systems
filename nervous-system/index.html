ระบบประสาทในชีวิตประจำวัน

เริ่มจากกิจกรรมใกล้ตัว แล้วค่อย ๆ ดูว่าการรับรู้ ความคิด การเคลื่อนไหว และข้อมูลย้อนกลับเชื่อมกันอย่างไร

ภาพจำลองการฝึกทักษะ 3 มิติระบบประสาทในชีวิตประจำวัน

จากสิ่งที่รับรู้ สู่การตอบสนอง

รับเข้า · เส้นประสาทส่วนปลายตา หู และความรู้สึกจากร่างกาย
สมอง · เครือข่ายหลายบริเวณใส่ใจและวางแผนเลือกสิ่งสำคัญ / คิดขั้นตอน
สมอง · เครือข่ายความจำใช้ประสบการณ์เดิมจำบริบท / เชื่อมสิ่งที่รู้
สมอง · ปมประสาทฐานช่วยเลือกการกระทำเกี่ยวข้องกับทักษะและนิสัย
สมอง · สมองน้อยปรับจังหวะและความแม่นช่วยการทรงตัว / เรียนรู้การเคลื่อนไหว
สมอง · บริเวณสั่งการเคลื่อนไหวส่งคำสั่งเคลื่อนไหว
สมองและวงจรอัตโนมัติปรับสภาวะร่างกายความตื่นตัว / การทำงานอวัยวะ
ไขสันหลัง → เส้นประสาทส่วนปลายส่งต่อสู่แขนและขา
ผ่านเส้นประสาทอัตโนมัติหัวใจและต่อมเหงื่อ
การตอบสนองของร่างกายกล้ามเนื้อเคลื่อนไหว → เกิดข้อมูลย้อนกลับ
เน้นวงจรที่กำลังอธิบายลูกศร = ทิศทางข้อมูลโดยย่อ
เกี่ยวกับแบบจำลองและแหล่งเรียนรู้

ภาพนี้ย่อกายวิภาคและแยกเวลาเพื่ออธิบายหลักการ กระบวนการจริงเกิดซ้อนกันและมีหลายวงจรร่วมกัน แสงและจุดวิ่งไม่ใช่ค่าจากการตรวจร่างกายหรือภาพสแกน

เรียนรู้เพิ่มเติมจาก OpenStax: Motor Responses และ งานวิจัยการเรียนรู้ทักษะและเครือข่ายสมอง
