### สิ่งที่เพิ่มในภาพจำลอง 3 มิติ

- เปรียบเทียบตอนเริ่มฝึกกับตอนคล่องแล้ว หมุนและซูมสองร่างพร้อมกัน
- ป้ายชื่อคลิกได้ 14 จุด ครอบคลุมสมอง ไขสันหลัง เส้นประสาท กล้ามเนื้อ และเอ็น
- สาธิต 6 ขั้น: วางแผน → คำสั่งผ่านไขสันหลัง → เส้นประสาทไปกล้ามเนื้อ → กล้ามเนื้อออกแรง → ข้อมูลย้อนกลับ → ปรับคำสั่งรอบถัดไป
- เล่นช้า 0.25× / 0.5× หรือความเร็ว 1× พร้อมปุ่มย้อนขั้นและดูขั้นถัดไป
- มีคำอธิบายความต่างของสองระยะในแต่ละขั้น และโหมดสำรวจอิสระ
- จำตัวเลือกในเบราว์เซอร์ของผู้ใช้ และรองรับการลดภาพเคลื่อนไหว

ดาวน์โหลดโฟลเดอร์โปรเจกต์ทั้งชุดแล้วเปิด `index.html` ได้เลย ภาพสามมิติต้องใช้เบราว์เซอร์ที่รองรับ WebGL และควรเก็บไฟล์ใน `assets/` ไว้ครบ โดยรวม Three.js ไว้ในโปรเจกต์แล้ว จึงไม่ต้องโหลดไลบรารีนี้จากเครือข่าย

ถ้าเปิด GitHub Pages จาก branch `main` และโฟลเดอร์ราก หน้า `/Education-Systems/` จะเป็นหน้าเมนูหลัก การอัปเดตนี้ไม่ได้เปลี่ยนการตั้งค่า hosting ของ repository

งานเดิมยังอยู่ที่ URL เดิม และไฟล์ [สรุปคลิป Markdown ต้นฉบับ](hinton-clips/อธิบาย-3-คลิป.md) เก็บไว้ตามเดิม
